# 翻译规则反馈收件箱（FEEDBACK）

协作过程中发现的规则缺口先记在这里。**这是收件箱，不是规则本身**：条目一旦被采纳（写进 `AGENTS.md`、检查脚本或 `SKILL.md`），就从这里删除，避免两处漂移。

## 记录格式

```
- [YYYY-MM-DD] <章节|通用> 一句话描述问题 → 建议落到哪里（AGENTS.md / check 脚本 / SKILL.md）
```

记录时机：
- 用户审读纠错时，若纠错根因是规则缺口而非一次性措辞偏好（用户说"记一下/这个要进规则"时必记）
- 检查脚本出现误报/漏报时
- 收尾回顾时（见 SKILL.md 阶段 5）

判断是否值得记：同类问题第二次出现，或用户明确表达偏好 → 记；一次性措辞调整 → 不记。
