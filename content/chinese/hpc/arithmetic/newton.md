实用算法很少被要求达到可能达到的最高精度。在真实世界的数据中，建模误差和测量误差通常比浮点数舍入这类来源的误差大几个数量级，而我们往往乐于选择一种用精度换速度的近似方法。

本节介绍这类近似数值算法中最重要的构件之一：*牛顿法*（Newton's method）。

## 牛顿法 {#newtons-method}

牛顿法是一个简单而非常强大的算法，用于求实值函数的近似根，也就是下列一般方程的解：

$$
f(x) = 0
$$

对函数 $f$ 的唯一假设是：至少存在一个根，且 $f(x)$ 在搜索区间上连续、可微。此外还有一些[无聊的角落情况](https://en.wikipedia.org/wiki/Newton%27s_method#Failure_analysis)，但它们在实践中几乎不会出现，所以我们干脆非正式地说这个函数是"好的"（good）。

算法的主要思想是：从某个初始近似 $x_0$ 出发，在 $x = x_i$ 处作函数图像的切线，把下一个近似 $x_{i+1}$ 取为切线与 $x$ 轴交点的 $x$ 坐标，如此迭代地改进。直觉是：如果函数 $f$ 是"[好的](https://en.wikipedia.org/wiki/Smoothness)"且 $x_i$ 已经足够接近根，那么 $x_{i+1}$ 会更接近。

![](/en/hpc/arithmetic/img/newton.png)

要求出 $x_n$ 处的交点，我们把切线函数置为零：

$$
0 = f(x_i) + (x_{i+1} - x_i) f'(x_i)
$$

由此解出

$$
x_{i+1} = x_i - \frac{f(x_i)}{f'(x_i)}
$$

牛顿法非常重要：它是科学与工程中一大类优化求解器的基础。

### 平方根 {#square-root}

作为一个简单的例子，我们来推导求平方根的算法：

$$
x = \sqrt n \iff x^2 = n \iff f(x) = x^2 - n = 0
$$

把 $f(x) = x^2 - n$ 代入上面的一般公式，得到如下更新规则：

$$
x_{i+1} = x_i - \frac{x_i^2 - n}{2 x_i} = \frac{x_i + n / x_i}{2}
$$

实践中我们还希望它在足够接近正确答案时尽快停下，这只需在每次迭代后检查一下：

```cpp
const double EPS = 1e-9;

double sqrt(double n) {
    double x = 1;
    while (abs(x * x - n) > eps)
        x = (x + n / x) / 2;
    return x;
}
```

该算法对许多函数都收敛，尽管只对其中某个子集（如凸函数）能可靠且可证明地收敛。另一个问题是：如果收敛发生，收敛得有多快。

仔细观察可以发现，正确数字的个数大约每轮迭代翻一倍。这种梦幻般的收敛速度并非巧合。

要定量分析收敛速度，我们需要考虑一个小相对误差 $\delta_i$（第 $i$ 轮迭代的），并确定下一轮迭代误差 $\delta_{i+1}$ 小了多少：

$$
|\delta_i| = \frac{|x_n - x|}{x}
$$

我们可以把 $x_i$ 表达为 $x \cdot (1 + \delta_i)$。把它代入牛顿迭代公式并将两边除以 $x$，得到

$$
1 + \delta_{i+1} = \frac{1}{2} (1 + \delta_i + \frac{1}{1 + \delta_i}) = \frac{1}{2} (1 + \delta_i + 1 - \delta_i + \delta_i^2 + o(\delta_i^2)) = 1 + \frac{\delta_i^2}{2} + o(\delta_i^2)
$$

这里我们把 $(1 + \delta_i)^{-1}$ 在 $0$ 处做了泰勒展开，用到误差 $d_i$ 很小的假设（既然序列收敛，$d_i \ll 1$ 对足够大的 $n$ 成立）。

整理出 $\delta_{i+1}$，我们得到

$$
\delta_{i+1} = \frac{\delta_i^2}{2} + o(\delta_i^2)
$$

这意味着：一旦足够接近解，误差在每次迭代后大约被平方（并减半）。由于对数 $(- \log_{10} \delta_i)$ 大致是答案 $x_i$ 中正确有效数字的个数，相对误差被平方恰好对应我们观察到的有效数字翻倍。

这被称为*二次收敛*（quadratic convergence），而且事实上它不只限于求平方根。详细证明留作读者练习，可以证明一般有

$$
|\delta_{i+1}| = \frac{|f''(x_i)|}{2 \cdot |f'(x_n)|} \cdot \delta_i^2
$$

在若干附加假设下——即 $f'(x)$ 不等于 $0$ 且 $f''(x)$ 连续——它至少给出二次收敛。
