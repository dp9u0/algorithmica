还有一些别的数学对象，其行为与模素数的余数相同。根据这些对象组成的集合保留了哪些性质，它们分别被称为*群*（group）、*环*（ring）和*域*（field）。

### 置换 {#permutations}

我们可以把置换的乘积定义为把一个置换作用于另一个置换。

这个运算满足结合律，因此可以用快速幂计算 $n$ 次幂，耗时 $O(n \log n)$。

![](/en/hpc/number-theory/img/permutation.png)

一般地，这被称为*置换群*（permutation group）；所谓*群*，就是定义了某个运算的元素集合。

### 单位根 {#roots-of-unity}

复数是形如 $a + bi$ 的数，其中 $a$、$b$ 是实数，$i$ 称为虚数单位：它是满足 $i^2 = -1$ 的数。

复数在代数中处理负数的平方根时很有用，因为 $i$ 在某种意义上等于 $\sqrt{-1}$。与负数一样，它们在现实世界里并不真的存在，只存在于数学家的头脑中。

用几何方式来思考复数最为方便。

复数的*模*（modulus）是实数 $r = \sqrt{a^2 + b^2}$。几何上，它是向量 $(a, b)$ 的长度。

复数的*辐角*（argument）是实数 $\phi \in (-\pi, \pi]$，满足 $\tan \phi = \frac{b}{a}$。几何上，它是向量 $(a, 0)$ 与 $(a, b)$ 之间的夹角。

这样我们就可以用极坐标来表示一个复数：

$$
a + bi = r \cdot ( \cos \phi + i \sin \phi )
$$

![](/en/hpc/number-theory/img/complex-plane.png)

这种表示之所以有用，是因为在需要把两个复数相乘时，用高中三角学就可以证明：不必做二项式展开，只需把它们的模相乘、辐角相加：

$$
\begin{aligned}
(a + bi) \cdot (c + di)
   &= r_1 \cdot ( \cos \phi_1 + i \sin \phi_1 ) \cdot r_2 \cdot ( \cos \phi_2 + i \sin \phi_2 )
\\ &= r_1 \cdot r_2 \cdot (\cos \phi_1 \cos \phi_2 - \sin \phi_1 \sin \phi_2 + i \cos \phi_1 \sin \phi_2 + i \cos \phi_2 \sin \phi_1 )
\\ &= r_1 \cdot r_2 \cdot (\cos (\phi_1 + \phi_2) + i \sin (\phi_1 + \phi_2) )
\end{aligned}
$$

现在，让我们**定义**欧拉数 $e$ 为满足下式的数：

$$
e^{i\phi} = \cos \phi + i \sin \phi
$$

也就是说，我们只是为 $(\cos \phi + i \sin \phi)$ 引入这样一个记号，而不去过多纠结把一个数自乘到复数指数到底意味着什么。几何上，所有这样的点都落在一个单位圆上。

这个记号很有用，因为我们可以把 $e^{i\phi}$ 当作普通的指数来处理。如果想把单位圆上辐角分别为 $a$ 和 $b$ 的两个复数相乘，只需写出

$$
(\cos a + i \sin a) \cdot (\cos b + i \sin b) = e^{i (a+b)}
$$

你可能会问，这一切和有限环有什么关系。事情是这样的：把单位圆上的复数相乘时，它们会像整数余数一样发生环绕。这样的数仍然有无穷多个，所以相似之处并不明显，但考虑这个问题：1 的 $n$ 次方根能有多少个？也就是那些自乘到 $n$ 次幂后会到达 1 的点。

结果是恰好有 $n$ 个，而且它们均匀分布。准确地说，它们是形如

$$
w_k = e^{i \tau \frac{k}{n}}
$$

的数，其中 $\tau$ 表示 $2 \pi$（一种[现代记号](https://tauday.com/tau-manifesto)）。

![](/en/hpc/number-theory/img/roots.png)

第一个根 $w_1$（更准确地说是第二个根，因为 $1$ 也是一个根）被称为生成单位根（generating root of unity）。把它自乘 1 次、2 次等等，会生成一个根的序列，$n$ 次之后开始循环。

$$
w_n = e^{i \tau \frac{n}{n}} = e^{i \tau} = e^{i \cdot 0} = w_0 = 1
$$

凡是不在单位圆上的数，其模要么太大要么太小；凡是辐角不被 $w_1$ 整除的数，其辐角就偏得太多。

这样的结构被称为环，或者更准确地说，*有限环*（finite ring）。

### 伽罗瓦域 {#galois-fields}

余数构成的是有限环。模素数的余数的不同之处在于，乘法总是存在逆运算，这种情况下它被称为*有限域*（finite field）。但素数并不是唯一能容纳有限域的集合大小。

素数大小的有限域的问题在于，在处理以 2 的幂为数据单位的计算机时，它们很浪费。

事实证明，还可以构造大小为 $p^k$ 的域，素数 $p$ 可以任取。这对计算机格外有用，因为可以取 $p=2$、$k=8$，一个字节恰好装得下这个集合的成员。

对非素数大小的域，就要放弃用整数表示的想法，改为把信息编码成一种特殊类型的多项式。首先选一个*不可约多项式*（irreducible polynomial）。例如对 GF(8)，$p(x) = x3 + x + 1$ 就是这样一个多项式：它无法被分解为乘积。

集合的成员由多项式的系数定义。由于每个系数非 0 即 1，正好共有 256 个成员。

加法定义为元素之间的按位异或，乘法定义为多项式相乘后用那个不可约多项式约减（做法可以类似于 GCD）。

异或在计算上没什么问题，而那种古怪的乘法可以干脆不做——利用元素并不多这一事实，预计算一张 256 个单字节条目的查找表即可。

这听起来很复杂，但一切都是为了拥有高效的实现：

```c++
char log[256], ilog[256];

char add(char x, char y) {
    return x ^ y;
}

char sub(char x, char y) {
    return x ^ y;
}

char mul(char x, char y) {
    return ilog[log[x] + log[y]];
}

char div(char x, char y) {
    return ilog[log[x] - log[y]];
}
```

这个域正是许多密码学和数据压缩技术的基础。事实上，就在你加载这个页面的时候，你的计算机已经把通信的全部内容都转换成了这种形式。
